# Riddler.Uxid

The .NET port of [uxid](https://github.com/riddler/uxid-ex): prefixed,
K-sortable identifiers a person can read, wire-compatible with the Elixir
`uxid` package.

This package is being built. The library holds no public API yet and no
version has been published; generation, decoding and the validity checks
arrive in later changes. This file is replaced by the full README before the
first release.
