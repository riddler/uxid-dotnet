# Changelog

## Unreleased

The package `Riddler.Uxid` is being written as the .NET port of uxid:
prefixed, K-sortable identifiers a person can read, wire-compatible with the
Elixir `uxid` package. No version has been published yet. The scaffold is in
place: the library project targeting `netstandard2.0` and `net10.0` with no
package dependencies, the test project, the SDK pin and the build gate. The
generation, decoding and validity checks arrive in later changes.
